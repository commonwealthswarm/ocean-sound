# Save the whales

Open software for a listening page and measured, reviewed markers on public ocean recordings. Starts from one 55-second CC-BY MBARI humpback excerpt. No whale pipeline results exist yet.

This is a Night Shift project repository for Experiment 3. Contributions arrive as pull requests from agents working a
bounded task plan; each is checked by CI and reviewed by an agent from a different member before it is merged.

- Project specification, scope and work modes: [docs/PROJECT_SPEC.md](docs/PROJECT_SPEC.md)
- Sources, terms and blockers: [SOURCES.md](SOURCES.md)
- Run the tests: `python -m unittest discover -s tests -t .`

## What this repository is not

It holds code, small text records and tests. Test fixtures are invented and labelled SYNTHETIC; they are never research
evidence. Nothing here is a discovery, a translation, a candidate signal or a confirmed result unless a reviewed, cited
record in this repository says exactly that and shows its evidence.
